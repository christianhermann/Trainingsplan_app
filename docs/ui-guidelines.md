# UI Guidelines

The app is a dark, mobile-first workout tool. It prioritizes fast reading and
logging over decoration.

## Screens

- Setup
- Today Workout / Timer
- Plan
- History
- Settings

## Layout

- Use vertically stacked cards rather than dense tables.
- Keep primary lifts visually more prominent than auxiliaries and accessories.
- Use readable working weights and large tap targets.
- Keep navigation shallow and predictable.
- Preserve useful workout information while the timer is open.

## Workout information

The Today and Plan screens should make these fields easy to find:

- week and training day
- exercise name
- working weight
- reps per set
- rep-out target
- set goal
- completed sets and last-set reps
- notes and video links

## Visual style

- dark background
- high-contrast text
- muted secondary text
- rounded cards
- consistent spacing
- one accent color for actions

Avoid spreadsheet-like layouts, tiny controls, unnecessary animation, and
dashboard clutter.
